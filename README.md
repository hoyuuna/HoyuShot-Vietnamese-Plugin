# Gói Ngôn Ngữ Tiếng Việt cho HoyuShot Camera

Bản dịch giao diện Tiếng Việt hoàn chỉnh, tự nhiên và chuyên nghiệp cho ứng dụng **HoyuShot**.

---

## Tính năng

- Bản dịch chuẩn thuật ngữ nhiếp ảnh cho toàn bộ các mục: Cảm biến, Màn trập, ISO, Cử chỉ, Phản hồi rung, Cập nhật hệ thống OTA.
- Cài đặt 1 chạm trực tiếp qua link Git.
- Tự động nhận diện bản cập nhật khi có bản dịch mới.
- Bật/tắt tức thì không cần khởi động lại ứng dụng.

---

## Hướng dẫn cài đặt

1. Mở ứng dụng **HoyuShot**.
2. Nhấn vào biểu tượng **Cài đặt (bánh răng)** > Chọn **Advanced Settings**.
3. Cuộn xuống mục **`04 // PLUGINS & EXTENSIONS`**.
4. Nhấn **`+ INSTALL PLUGIN`**.
5. Dán link Git repository của gói ngôn ngữ:
   ```
   https://github.com/<your-username>/vietnamese-language-pack.git
   ```
6. Nhấn **`CLONE & INSTALL`**.
7. Bật nút chuyển trạng thái sang **ACTIVE** để áp dụng giao diện Tiếng Việt ngay lập tức!
